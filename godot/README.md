# Touchline Dynasty — Android Football Career Game

An original football-management game made in **Godot 4.4.1** for portrait Android phones, not a WebView or Android dashboard.

## Playable career systems
- Start as manager of any of eleven National Championship clubs.
- Two 11-team divisions, double round-robin fixtures, live 90-minute match simulation, league tables.
- Tactical formations, mentality, pressing, defensive line, passing instructions and set-piece roles.
- Player database (procedurally generated fictional players), OVR/POT, age, fitness, morale, contracts, salaries and seasonal growth.
- Scouting, shortlists, transfer offers and permanent transfers.
- Stadium expansion, training, academy, scouting facilities, budgets and matchday revenue.
- Promotion, relegation, season prizes, multi-season progression, board confidence and inbox.
- Persistent local career saved to `user://touchline_save.json`.

## Build
Open `godot/project.godot` in Godot 4.4.1. For Android, use the export preset or the GitHub Actions workflow `Touchline Dynasty Godot Android APK` on the `touchline-dynasty-godot` branch.

## Content and licensing
This game deliberately uses fictional teams and generated players because commercial redistribution of third-party player ratings, images, league marks and crests requires permission or an appropriate license. No claim of real-time official match data.

## Scope
A playable offline management game, not a fully licensed AAA FIFA/Football Manager equivalent. The Android APK is a debug build until separately signed and tested for release.
